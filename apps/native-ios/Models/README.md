# Models

The Best Quality Core ML models are **not bundled** in the app — they download on
demand from R2 (`models-data.hakobs.com`) and cache in Application Support. See
`ModelDownloader.swift`.

Drop a `<Name>.mlpackage` here only if you want to bundle it for offline use; the
providers in `InferenceModel` currently point at the downloaded copy, so bundling
also requires switching them back to `BundledModelProvider`.

Models are versioned in [imagekid-models](https://github.com/silvandiepen/imagekid-models)
and generated by `tools/coreml-conversion` in the main repo.
