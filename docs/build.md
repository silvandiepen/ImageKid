# Build and run

Requirements: macOS 14+, Xcode 16+, and Swift 5.10+.

Open `Package.swift` in Xcode, select the `ImageKid` scheme, and run on My Mac.

Terminal commands:

```bash
make build
make test
make run
```

The current Swift package is a development foundation. Signing, sandbox entitlements, an asset catalogue, archive settings, and notarisation are separate distribution tasks.
